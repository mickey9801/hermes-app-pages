Privacy Policy

Last updated: 2026-10-25

This application ("Hermes Agent") is a personal automation tool used only by its developer on a single Google account. It is not offered as a service to any other user.

Google Workspace API data

The application accesses Google Workspace data (Gmail messages, Calendar events, Drive files, Docs, Sheets, Slides, Forms, Tasks and Contacts) belonging only to the authorised user, via official Google APIs, strictly within the OAuth scopes the user approved at consent time.

This data is processed locally on the developer's own computer to perform the requested personal-assistant tasks (reading and drafting mail, organising files and events).

Our commitment

  • No collection: the application does not collect Google API data beyond what is needed for the single user's own tasks.
  • No sharing or selling: Google API data is never shared with, sold to, or disclosed to any third party.
  • No advertising: no ads are shown, and no advertising tracking or behavioural profiling is performed with Google API data.
  • No human review: Google API data is not reviewed by humans, except by the authorised user themselves.
  • Storage: data remains in the user's own Google account; any local copies stay on the developer's own machine and can be deleted at any time.

Revoking access

The user may revoke the application's access at any time at myaccount.google.com/permissions.
